====================
HOW TO USE THIS CALCULATOR
====================

COST CALCULATION METHODOLOGY:

1. BASE COST: Standard costs for central Germany (Dresden/Leipzig region)
2. REGIONAL FACTOR: Apply multiplier based on location
3. QUALITY TIER: Select budget/standard/premium/luxury
4. SIZE FACTOR: Calculate per sqm or per unit
5. COMPLEXITY FACTOR: Adjust for special circumstances
6. CONTINGENCY: Add 10-15% buffer for unforeseen costs
